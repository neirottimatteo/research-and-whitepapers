# 2026-05-01 — Feature Addition, Ablation, and Monte Carlo

## Summary

Two sessions of work spread across April 30 – May 1:

1. **Ablation run on existing features** — Monte Carlo drop-mode flagged 6 features as causing DangerFP without meaningful AUC gain. They were temporarily removed, but empirical walk-forward results were worse; all 6 were restored to `FEATURE_COLS_E`.
2. **25 new features added** — four thematic groups (SLOOS, Delinquency, Liquidity/Momentum, Financial Spreads) were fetched, engineered, and stored in a new `FEATURE_COLS_E_FULL` list.
3. **Ablation run on new features** — all 25 new features were tested in add-mode and every single one came back EXCLUDE or HARMFUL; none were promoted to the baseline.
4. **Walk-forward and FP-detection improvements** — tighter DangerFP sensitivity (fold ≥ 8), explicit COVID-2020 exclusion window, `dangerous_streaks` surfaced in return dict.
5. **Infrastructure** — retry logic on FRED API, rate-limit throttle, `--feature-set` CLI flag, SHAP timeline chart.

## Ablation drop-mode findings (1000 iterations)

Monte Carlo drop-mode ran 1000 iterations. A feature is marked REMOVE when its average `ΔDangerFP` is positive (presence causes extra dangerous false positives) regardless of small AUC gains.

| Feature | AUC gain | AvgFP cost | Ablation verdict |
|---|---|---|---|
| `houst_3m` | +0.0023 | +2.612 | REMOVE |
| `pce_yoy` | +0.0009 | +2.246 | REMOVE |
| `sentiment_lvl` | +0.0011 | +1.088 | REMOVE |
| `houst_yoy` | −0.0019 | +1.057 | REMOVE |
| `mfg_sales_yoy` | −0.0008 | +0.259 | REMOVE |
| `truck_sales_yoy` | −0.0013 | +0.089 | REMOVE |

`sentiment_yoy` and `sentiment_3m_chg` were NEUTRAL — kept. `permit_yoy` was NEUTRAL with a strong negative FP score (−4.6) — kept.

**These 6 features were temporarily removed, but subsequent walk-forward validation showed overall model performance was worse without them. All 6 were restored to `FEATURE_COLS_E`.** The ablation score is a statistical signal, not a guarantee — the features interact with the rest of the set in ways the marginal ablation doesn't capture.

### SLOOS: Credit "Off" Switch (4 features, from ~1990)
- `sloos_ci_large_lvl`, `sloos_ci_small_lvl` — raw level; >0 = net tightening, >25 = historical recession precursor
- `sloos_tightening` — binary: any net tightening for large/mid firms
- `sloos_stress` — binary: level > 25 (historically precedes recession)

### Delinquency Canaries (5 features, from 1987–1991)
- `delq_credit_card_lvl`, `delq_credit_card_yoy`
- `delq_ci_lvl` — business loan delinquency
- `delq_mortgage_lvl`, `delq_mortgage_yoy`

### Structural Liquidity & Momentum (4 features)
- `m2real_yoy`, `m2real_3m` — real money supply growth (from 1959)
- `fed_assets_yoy` — Fed balance sheet YoY (from 2002; QE/QT proxy)
- `reallnresn_yoy` — residential lending growth (from ~2004)

### Forward-Looking Business Intent / CapEx (5 features)
- `neworder_yoy`, `neworder_3m` — capital goods orders (from 1992)
- `jolts_yoy` — labor demand (from 2000-12)
- `overtime_lvl`, `overtime_3m_chg` — overtime hours (from 1956)

### High-Stress Financial Spreads (7 features)
- `hy_spread_lvl`, `hy_spread_3m_chg`, `hy_spread_high` (>500 bps) — HY OAS (from 1996-12)

- `t10y3m_lvl`, `t10y3m_inverted` — 10Y–3M yield spread (from 1982)

## Ablation result: new features (add-mode, 1790 iterations)

All 25 new features were tested in Monte Carlo add-mode. **Every feature came back EXCLUDE or HARMFUL** — none were promoted to the baseline `FEATURE_COLS_E`.

The two worst were:
- `m2real_yoy` — HARMFUL: −0.0240 AUC, +2.28 AvgFP
- `m2real_3m` — HARMFUL: −0.0058 AUC, +1.15 AvgFP

The least harmful were `jolts_yoy` and `overtime_3m_chg` (borderline EXCLUDE, small negative AUC and small FP increase), but still did not pass the strict rule (avg ΔDangerFP > 0 → EXCLUDE).

**Conclusion:** The 25 new features are available via `--feature-set full` but are NOT part of the production baseline. The production model continues to use `FEATURE_COLS_E`.

## Code changes

### `config.py`
- Added `DANGER_FP_EXCLUDE_START = 2020-01-01` and `DANGER_FP_EXCLUDE_END = 2020-12-31`.
  - Rationale: any DangerFP streak starting in 2020 is a structural artifact (the model was never trained on 2019-02/2020-12 labels), not a real false alarm. Excluded from DangerFP counts.

### `data_finder.py`
- Added 11 new FRED series to `FRED_SERIES`.
- `_fetch_one_fredapi`: added retry loop (4 attempts, 10 s delay) for transient server errors.
- `_fetch_series`: added 2 s throttle before each download to stay under FRED rate limits.
- `load_raw`: now defaults to `api_key=FRED_API_KEY, use_cache=CACHE_DATA` from config.
- `_build_features`: added all 25 new feature computations.
- `FEATURE_COLS_E`: temporarily removed 6 ablation-flagged features, then restored all 6 after walk-forward showed worse performance without them. Baseline unchanged.
- `FEATURE_COLS_E_FULL`: new list = `FEATURE_COLS_E + [25 new features]`.

### `walk_forward.py`
- Imported `DANGER_FP_EXCLUDE_START/END` from config and `FEATURE_COLS_E_FULL` from data_finder.
- `run_walk_forward` and `run_ensemble_walk_forward`: added `feature_cols_override` parameter; pass `FEATURE_COLS_E_FULL` when `--feature-set full`.
- DangerFP threshold lowered from `fold ≥ 9` to `fold ≥ 8` (catches one extra fold of history).
- DangerFP streaks in the 2020 COVID window are now excluded via the new config constants.
- `dangerous_streaks` list is now included in the walk-forward return dict.
- Removed the unused `COVID_OFFSET` constant.
- Added `--feature-set {baseline,full}` CLI argument (default: `baseline`).

### New files
- `ablation.py` — Monte Carlo ablation engine (475 lines). Supports drop-mode and add-mode. Produces `output/raw/ablation_results.csv`.
- `feature_search.py` — systematic feature search utility (545 lines). Produces `output/raw/feature_search.csv` and `output/raw/feature_search_drop.csv`.
- `documentation/MonteCarlo.md` — documents the ablation methodology and results.
- `documentation/features.md` — documents all features in `FEATURE_COLS_E` and `FEATURE_COLS_E_FULL`.

### Output updated
- New SHAP timeline chart: `output/html/viz_shap_timeline_e_xgboost_ens.html` / `.png`
- New SHAP waterfall for 2025-04: `output/images/viz_shap_waterfall_e_xgboost_ens_2025-04.png`
