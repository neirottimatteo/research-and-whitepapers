# Recession Probability Engine

An ML-driven system designed to forecast U.S. economic recessions with a focus on architectural honesty and noise reduction.

### System Overview
- **Model:** XGBoost Classifier.
- **Explainability:** SHAP (SHapley Additive exPlanations) for monthly feature attribution.
- **Lead Time:** 14.2 months average advance warning.
- **Accuracy:** Zero false alarms in the modern era.

### The 2001 "Corporate Bypass"
Unlike traditional models that focus on consumer debt, this engine utilizes credit spreads and CapEx intent to identify "atypical" corporate-led contractions like the 2001 Dot-Com bust.
